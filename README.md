# 📈 Easy-DART (핑거다트)
> **20대 사회초년생의 '첫 투자 지갑 지킴이' | 게이미피케이션 & 교육공학 기반 체감형 DART 공시 러닝 플랫폼**

---

## 📌 1. 기획 배경 및 타겟 페르소나 (Target Persona)

### 1.1 기획 의도: 왜 20대 사회초년생인가?
- **주식 투자의 대중화 vs 금융 문해력(Financial Literacy)의 양극화**:  
  최근 20대 청년들은 첫 월급이나 아르바이트 소득으로 주식 투자를 시작하지만, 50페이지가 넘는 금융감독원 전자공시(DART) 보고서의 난해한 한자식 회계 용어와 복잡한 재무제표에 압도당합니다.
- **정보 비대칭과 묻지마 투자의 악순환**:  
  공시를 읽지 못해 유튜브, 리딩방, 지인 추천 등 '묻지마 테마주'에 원금을 투자했다가 **[감사의견 거절]**, **[완전자본잠식]** 같은 전형적인 상장폐지 지뢰를 밟고 소중한 초기 자본을 잃는 사례가 빈번합니다.
- **Easy-DART의 미션**:  
  **"내 월급과 시드를 지키는 최소한의 안전장치!"**  
  투자 손실 위험이 전혀 없는 안전한 가상 샌드박스에서, 일상 소비 브랜드(올리브영·다이소 등)와 아케이드 게임을 통해 공시를 손끝으로 체득하도록 돕습니다.

### 1.2 핵심 타겟 페르소나: "26세 사회초년생 김주린"

| 항목 | 프로필 및 사용자 맥락 |
| :--- | :--- |
| **기본 인적사항** | 26세, 취업 1년 차 직장인, 월급 250만 원 중 적금 100만 원 외 매월 30만 원으로 주식 입문 희망 |
| **투자 성향 & 고민** | "주식 시작해야 돈을 모은다는데, 재무제표는 외계어 같고 차트만 보면 머리가 아파요. 상장폐지만은 절대 당하고 싶지 않아요." |
| **핵심 Pain Points** | 1. **공시 울렁증**: DART 사이트에 들어가면 수십 쪽 분량의 텍스트에 질려 1분 만에 닫음.<br>2. **개념과 현실의 괴리**: '영업이익'과 '당기순이익'의 차이를 교과서로 봐도 실전에서 어떤 의미인지 모름.<br>3. **시간 부족**: 퇴근 후 1~2시간씩 각 잡고 금융 강의를 들을 체력과 여유가 없음. |
| **Easy-DART의 솔루션** | - **출퇴근 3분 마이크로 러닝**: 지하철에서 스마트폰으로 가볍게 즐기는 1분 퀴즈와 3초 스와이프 심사.<br>- **체험 기반 위험 회피**: 게임 속에서 상폐 지뢰를 직접 요격하고 회피해보며 본능적인 위험 감별력 체화.<br>- **소비 메타포 환산**: "올리브영 립스틱 몇 개를 팔아야 이 회사의 영업이익이 될까?" 같은 직관적 비유 해설. |

## 🧠 2. 교육학적 설계 프레임워크 (Pedagogical Framework)

Easy-DART는 단순한 '재미 위주의 미니게임'에 그치지 않고, **검증된 현대 교육학 및 인지심리학 이론**을 아키텍처 전반에 체계적으로 적용하였습니다.

```
[ Easy-DART 교육학적 4단계 학습 사다리 (Scaffolding Architecture) ]

   (4단계) 🤖 AI 1:1 하브루타 디브리핑 (평가 및 메타인지 구축)
          ▲
   (3단계) 🕹️ 3대 실전 아케이드 (체감형 적용 및 스키마 형성)
          ▲
   (2단계) 📚 1분 마이크로 퀴즈 (용어 기억 & 개념 이해)
          ▲
   (1단계) 🛍️ 친숙한 소비 브랜드 탐색 (선행지식 활성화)
```

### 2.1 비고츠키의 비계 설정 (Scaffolding & ZPD: 근접발달영역)
- **근접발달영역(ZPD)**: 학습자가 혼자서는 풀 수 없지만, 적절한 발판(Scaffolding)이 주어지면 도달할 수 있는 학습 잠재 영역을 뜻합니다.
- **단계별 발판 설계**:
  1. **1단계 (선행지식 활성화)**: 20대가 매일 이용하는 올리브영, 다이소, 스타벅스 등의 익숙한 소비 맥락으로 진입 장벽 제거.
  2. **2단계 (개념 비계)**: 15문항의 정예 '1분 기초 용어 퀴즈'로 기본 어휘(영업이익, 감사의견, CB 등)를 무작위 셔플로 탄탄히 다짐.
  3. **3단계 (체감 비계)**: 3대 아케이드(슈팅/심사/러너)를 통해 공시 텍스트를 행동과 직관으로 체화.
  4. **4단계 (심화 및 자립)**: AI 기반 맞춤형 오답 디브리핑으로 학습자가 스스로 오류를 성찰하고 실전 DART 공시 원문을 읽을 수 있도록 지원.

### 2.2 콜브의 경험학습 4단계 순환 모델 (Kolb's Experiential Learning Cycle)
학습은 지식의 단순 수용이 아니라 **경험의 변형 과정**을 통해 완성된다는 데이비드 콜브(David Kolb)의 이론을 루프로 구현했습니다:
1. **구체적 경험 (Concrete Experience)**: 게임 속에서 떨어지거나 질주해오는 공시 키워드와 직접 맞닥뜨림.
2. **반성적 관찰 (Reflective Observation)**: 게임 오버 화면에서 점수, 회피율, 놓친 공시 오답노트를 확인하며 플레이 복기.
3. **추상적 개념화 (Abstract Conceptualization)**: "아, [전환사채 발행]은 주식 수가 늘어나서 기존 주주 가치가 희석되는 악재구나!"라는 금융 법칙 도출.
4. **능동적 실험 (Active Experimentation)**: 다음 판 플레이 또는 모의 투자에서 해당 공시가 나왔을 때 즉각 올바른 결정을 내림.

### 2.3 스웰러의 인지 부하 이론 (Cognitive Load Theory)
- **외재적 인지 부하(Extraneous Load)의 파격적 제거**:  
  수십 쪽에 달하는 복잡한 서식과 표, 법률적 미사여구를 완전히 걷어내고, **"핵심 공시 카드 1장"** 또는 **"3초 선택지"**로 극단적 마이크로 캡슐화.
- **본유적 인지 부하(Germane Load)의 집중 활성화**:  
  학습자의 인지 자원을 "이 공시가 기업의 존속에 위협이 되는가(악재)? 아니면 이익을 늘리는가(호재)?"라는 **핵심 인지 스키마(Schema) 형성**에 100% 집중시킵니다.

### 2.4 블룸의 신 교육목표분류학 (Revised Bloom's Taxonomy) 4단계 매핑

| 인지 도메인 | 학습 목표 | Easy-DART 구현 기능 |
| :--- | :--- | :--- |
| **1. 기억/이해 (Remember/Understand)** | 핵심 회계·공시 용어의 정의를 설명할 수 있다. | **1분 기초 용어 퀴즈** (손익/감사/지표 15문항 무작위 셔플) |
| **2. 적용 (Apply)** | 공시 텍스트를 보고 호재와 악재를 즉각 판별하여 행동할 수 있다. | **Machine 01 (슈팅)** & **Machine 03 (러너)** (0.5초 식별 액션) |
| **3. 분석 (Analyze)** | 실제 기업의 공시 카드를 읽고 투자 매수/손절 여부를 비판적으로 판단한다. | **Machine 02 (투자 심사관)** (정독 기반 3초 번개 판정) |
| **4. 평가 (Evaluate)** | 자신의 투자 오답 이유를 분석하고 기업의 재무 건전성을 최종 진단한다. | **AI 맞춤형 하브루타 디브리핑** (대화형 메타인지 복기) |

### 2.5 마이크로러닝 & 간격 반복 (Microlearning & Spaced Repetition)
- 에빙하우스 망각곡선 극복을 위해, 1회 플레이 시간을 **1분~3분 단위의 마이크로 세션**으로 분할.
- 접속할 때마다 문항과 보기 번호가 뒤섞이는 **2-Level 피셔-예이츠 셔플(Fisher-Yates Shuffle)**을 적용하여 단순 위치 암기를 방지하고 장기기억으로 전이.

## 🕹️ 3. 게이미피케이션 아키텍처 (Game-based Learning System)

Easy-DART의 게임 엔진은 **"텍스트를 정독하고 판별하지 않으면 조작할 수 없는 인터랙션"**을 핵심 철학으로 삼습니다.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    🕹️ Easy-DART 3대 정예 아케이드 라인업                 │
├─────────────────────────┬─────────────────────────┬─────────────────────┤
│ 🧠 Machine 01           │ ⚖️ Machine 02           │ 🏎️ Machine 03       │
│ 주식 & 회계 기초 퀴즈   │ DART 실전 투자 심사관   │ DART 급행 레인 러너 │
│ [ 💡 문해력 배틀 ]      │ [ ⚡ 3초 뇌지컬 ]       │ [ 🕹️ 반사신경 ]     │
│ 62종 대용량 무한 퀴즈   │ 실제 공시 카드 BUY/SELL │ 차선 변경 호재 획득 │
└─────────────────────────┴─────────────────────────┴─────────────────────┘
```

### 3.1 3대 정예 금융 아케이드

1. **🧠 Machine 01: 주식 & 회계 기초 퀴즈 아레나 (`quiz_preview.html` / `quiz_terms/index.html`)**
   - **조작 및 메커니즘**: 4지선다형 스피드 퀴즈, 연속 정답 시 콤보 배수 보너스(+100P~).
   - **대용량 퀴즈 데이터베이스 (62문항 완비)**:
     - 💰 **손익 & 본업 마진**: 매출액, 영업이익, 당기순이익, OPM, 감가상각비, 판관비, 흑자/적자전환, EBITDA 등 (12문항)
     - 🏦 **재무상태 & 건전성**: 자산=부채+자본, 부채비율, 유동비율, 완전/부분자본잠식, 결손금, 잉여금, BPS 등 (10문항)
     - 🚨 **감사보고서 & 상폐 지뢰**: 감사의견 4단계, 관리종목, 투자주의환기종목, 상장적격성 실질심사, 횡령·배임 등 (12문항)
     - 💣 **CB & 유상증자**: 전환사채(CB), 신주인수권부사채(BW), 교환사채(EB), 리픽싱, 주주배정 vs 제3자배정 등 (10문항)
     - 📈 **배당 & 밸류에이션**: 자사주 매입 vs 소각, 배당성향, 배당수익률, PER, PBR, ROE, 액면분할 등 (10문항)
     - 📑 **DART 실전 공시**: 전자공시 5% 룰, 최대주주 변경, 단일판매 공급계약, 조회공시 요구 등 (8문항)
   - **무한 스트리밍 셔플**: 2단계 피셔-예이츠(Fisher-Yates) 셔플로 순서가 무작위 순환되어 고갈 없이 무제한 플레이 지원.
   - **교육 효과**: 20대 사회초년생의 실제 지갑과 직결되는 핵심 금융 문해력(FQ)을 탄탄하게 확립.

2. **⚖️ Machine 02: DART 실전 투자 심사관 (`judge.html`)**
   - **조작 및 메커니즘**: 키보드 `◀` (손절/SELL) vs `▶` (매수/BUY), 또는 터치 스와이프.
   - **정독과 속도의 조화**: 올리브영, 다이소 등 20대 일상 기업의 실제 공시 카드가 1장씩 제시됨. 제한시간(기본 8초) 내 정독 후 판정.
   - **⚡ 3초 번개 보너스**: 3초 이내에 본질을 꿰뚫고 올바르게 판정 시 +100P 추가 보너스.
   - **교육 효과**: 실제 공시 원문 독해력 증진 및 인지 부하 최적화 가치 판단력 훈련.

3. **🏎️ Machine 03: DART 급행 레인 러너 (`runner.html`)**
   - **조작 및 메커니즘**: `◀` `▶` 차선 변경, `▲` 가속 부스터, `▼` 급제동.
   - **동체 시력 훈련**: 3개 차선으로 다가오는 공시 캡슐 중 호재(`영업이익 서프라이즈`, `배당 확대`)는 먹고, 악재 지뢰(`부채비율 900%`, `대표이사 횡령`)는 회피.
   - **교육 효과**: 순간적인 텍스트 동체 시력과 반사신경 기반의 위험 회피 본능 각인.

*(참고: 기존 레이더 미사일 슈팅 게임은 `dart_shooter_preview.html` 및 `radar_shooter.html` 아카이브로 온전히 보존되어 있습니다.)*

### 3.3 무계정(No-Login) 명예의 전당 & 주린이 승급제
- **개인정보/로그인 부담 제로**: 브라우저 `localStorage`를 활용하여 원클릭 닉네임 입력만으로 게임 기록 영구 보존.
- **실시간 명예의 전당 (TOP 5)**: 메인 화면에 🥇 1위~5위 랭킹 전광판 실시간 렌더링 및 `MY` 기록 하이라이트.
- **4단계 주린이 성장 사다리**:
  - 🐣 `새싹 주린이 (LV.1)` ➔ 🔍 `노련한 지뢰 감별사 (LV.2)` ➔ 🐜🔥 `날렵한 여의도 불개미 (LV.3)` ➔ 👑 `스마트 머니 (LV.MAX)`

## 🤖 4. [게임 파트 전담] AI 기능 융합 로드맵 (AI-Powered Game & Quiz)

팀원 C(게임/퀴즈 파트)는 단순한 미니게임을 넘어, **LLM(Gemini) 인공지능 기술을 게임 코어 루프와 결합하여 20대 주린이의 실전 투자 문해력을 극대화하는 5대 인게임 AI 시스템**을 구축합니다.

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        🕹️ 게임 & 퀴즈 전담 5대 인게임 AI 아키텍처                      │
├─────────────────────────┬─────────────────────────┬────────────────────────────────────┤
│ 1. 1:1 하브루타 오답처방 │ 2. 무한 공시 퀘스트 생성│ 3. AI 투자 페르소나 진단           │
│ (Post-Game Debriefing)  │ (Procedural Scenarios)  │ (Behavioral Persona Diagnostic)    │
│ "왜 CB 발행을 호재로    │ 매일 20대 일상 기업 신규│ 플레이 로그(속도/욕심/회피율) 기반 │
│  보셨나요? 주주가치 문답│ 공시 딜레마 카드 무한생성│ "돌격형 불개미 vs 냉철한 헌터" 진단│
├─────────────────────────┼─────────────────────────┴────────────────────────────────────┤
│ 4. AI 동적 난이도 조절  │ 5. 퀴즈 즉시 심화 질문 (In-Quiz AI Deep Dive)                  │
│ (Dynamic Difficulty)    │ "아직 이해가 안 돼요!" 클릭 시 20대 알바/월급 비유 3줄 해설   │
│ 주린이 좌절 방지 밸런싱 │                                                              │
└─────────────────────────┴──────────────────────────────────────────────────────────────┘
```

### 4.1 🎮 게임 오버 AI 1:1 하브루타 오답 처방전 (Post-Game AI Socratic Debriefing)
- **문제점**: 기존 게임은 게임 오버 시 점수만 보여주고 끝나, 플레이어가 "내가 왜 틀렸는지, 실전 주식에서 왜 위험한지"를 전혀 깨닫지 못함.
- **해결 솔루션**: 게임 오버 화면에서 내가 실수한 공시(예: '감사의견 거절' 미사일 요격 실패, '전환사채(CB)' 매수 오판)를 Gemini AI가 1:1 대화형 하브루타(소크라테스식 문답)로 코칭.
- **인게임 코칭 시나리오**:
  > **🤖 AI 투자 코치**: "주린 님! 방금 2호기 심사관 게임에서 `[전환사채(CB) 500억 발행]` 공시를 보고 **우측 스와이프(매수/호재)**를 하셨네요! 회사가 돈을 빌려오니 당장은 호재처럼 보일 수 있어요. 하지만 나중에 이 채권이 '신규 주식'으로 시장에 쏟아져 나오면, 기존 주주들의 주식 1주당 가치는 어떻게 될까요?"  
  > **👤 사용자**: "주식 수가 많아지니까 내 지분 가치가 떨어질 것 같아요."  
  > **🤖 AI 투자 코치**: "정확합니다! 그걸 금융 전문 용어로 **'주주가치 희석(Dilution)'**이라고 불러요. 그래서 실전 시장에서는 주가가 급락하는 악재가 된답니다. 다음번엔 꼭 좌측(손절)으로 넘겨보세요!"

---

### 4.2 🎲 무한 실전 공시 시나리오 생성 엔진 (AI Procedural Disclosure Generator)
- **문제점**: 게임에 탑재된 공시 데이터가 고정되어 있으면, 몇 번 플레이 후 암기 게임으로 변질되어 리플레이 가치(Replayability)가 급감함.
- **해결 솔루션**: 백엔드 `quiz_service.py`와 연동하여, Gemini AI가 20대 실생활 기업(무신사, 배달의민족, 당근마켓, 토스, 야놀자 등)의 **현실감 넘치는 가상/실전 공시 딜레마 카드**를 실시간으로 무한 생성.
- **적용 게임**:
  - **Machine 02 (투자 심사관)**: "배달의민족, 라이더 배달료 20% 인상 vs 당기순손실 전환" ➔ BUY/SELL 3초 판단 카드로 즉각 출제.
  - **Machine 01 (레이더 슈팅)**: 매 판 새로운 타깃 공시 텍스트가 무작위 파생 낙하.

---

### 4.3 📊 플레이 로그 기반 'AI 주린이 투자 성향 진단서' (AI Behavioral Persona Diagnostic)
- **개념**: 3대 아케이드 게임을 플레이하는 동안 기록된 행동 데이터(평균 반응 속도 ms, 호재 탐욕 지수, 악재 회피 정확도, 3초 번개 보너스 성공률)를 AI가 종합 채점.
- **진단 결과 예시**:
  - 🐜 **"돌격형 여의도 불개미"**: "호재 반응 속도는 0.8초로 최상위권이지만, 감사의견 거절 등 치명적인 상폐 지뢰를 2번이나 밟았습니다! 고수익을 쫓다 깡통을 찰 위험이 있으니 1호기 슈팅으로 지뢰 회피 훈련을 3회 더 추천합니다."
  - 🦉 **"신중한 가치 헌터"**: "평균 판단 시간 6.2초로 신중하며 오답률 0%! 다만 3초 번개 보너스를 놓치는 경향이 있어 실전 매매 타이밍을 잡는 연습이 필요합니다."
- **소셜 공유 카드**: 게임 종료 후 친구들에게 자랑할 수 있는 감각적인 픽셀아트 성향 진단 카드 발급.

---

### 4.4 ⚡ 인지 부하 최적화 AI 동적 난이도 조절 (AI Dynamic Difficulty Balancing - DDA)
- **개념**: 초보 주린이가 게임 시작 10초 만에 게임 오버를 당해 학습을 포기(Choke)하지 않도록, AI가 플레이어의 숙련도를 실시간 트래킹하여 난이도를 미세 조절(Flow State 유지).
- **조절 매개변수**:
  - **1단계 (초보 감지)**: 공시 낙하 속도 감속, 3초 보너스 유예시간 연장, 공시 카드 핵심 키워드(예: <span style="color:#f43f5e">완전자본잠식</span>) 자동 형광펜 하이라이트.
  - **2단계 (숙련 감지)**: 낙하 속도 가속, 복합 공시(호재와 악재가 섞인 애매한 공시) 출제 비중 상향.

---

### 4.5 💬 1분 기초 퀴즈 즉시 AI 심화 해설 (In-Quiz AI Deep Dive on Demand)
- **개념**: 15문항 용어 퀴즈 풀이 후, 정적 해설을 읽어도 감이 안 올 때 **`[🤖 AI 튜터에게 더 쉽게 물어보기]`** 버튼 클릭.
- **20대 눈높이 3줄 비유 답변**:
  - 질문: *"감가상각비가 왜 현금이 안 나가는 비용인가요?"*
  - AI 답변: *"작년에 200만 원 주고 산 맥북을 4년 동안 쓴다고 칠 때, 매년 50만 원씩 가치가 닳았다고 장부에 적는 거예요! 이미 작년에 결제했으니 올해 내 지갑에서 나간 돈은 0원이지만, 장부상으로는 비용 처리하는 마법이랍니다."*

## 🚀 7. 빠른 시작 가이드 (Quick Start)

### 7.1 백엔드 환경변수 설정 (`.env`)
루트 경로의 [`.env`](.env) 파일에 API 키를 입력합니다:
```env
DART_API_KEY=your_dart_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
HOST=0.0.0.0
PORT=8080
```

### 7.2 원클릭 서버 실행 (`run.sh`)
Git Bash 터미널에서 아래 명령어를 실행하면 가상환경 구성, 패키지 설치, 풀스택 서버 구동이 원클릭으로 진행됩니다:
```bash
bash run.sh
```

- 🏢 **기업 목록**: `http://localhost:8080/company-list`
- 📊 **기업 공시 상세**: `http://localhost:8080/company-details?company=olive`
- 🕹️ **퀴즈 & 아케이드**: `http://localhost:8080/quiz`
