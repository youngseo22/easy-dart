# 📈 Easy-DART (핑거다트)
> **20대 사회초년생의 '첫 투자 지갑 지킴이' | 게이미피케이션 & 교육공학 기반 체감형 DART 공시 러닝 플랫폼**

## 📌 1. 기획 배경 및 타겟 페르소나 (Target Persona)

### 1.1 기획 의도: 왜 20대 사회초년생인가?
- **주식 투자의 대중화 vs 금융 문해력(Financial Literacy)의 양극화**:  
  최근 20대 청년들은 첫 월급이나 아르바이트 소득으로 주식 투자를 시작하지만, 50페이지가 넘는 금융감독원 전자공시(DART) 보고서의 난해한 한자식 회계 용어와 복잡한 재무제표에 압도당합니다.
- **정보 비대칭과 묻지마 투자의 악순환**:  
  공시를 읽지 못해 유튜브, 리딩방, 지인 추천 등 '묻지마 테마주'에 원금을 투자했다가 **[감사의견 거절]**, **[완전자본잠식]** 같은 전형적인 상장폐지 지뢰를 밟고 소중한 초기 자본을 잃는 사례가 빈번합니다.
- **Easy-DART의 미션**:  
  **"내 월급과 시드를 지키는 최소한의 안전장치!"**  
  투자 손실 위험이 전혀 없는 안전한 가상 샌드박스에서, 일상 소비 브랜드(올리브영·다이소 등)와 아케이드 게임을 통해 공시를 손끝으로 체득하도록 돕습니다.

### 1.2 핵심 타겟 페르소나: "26세 사회초년생 김주린"

| 항목 | 프로필 및 사용자 맥락 |
| :--- | :--- |
| **기본 인적사항** | 26세, 취업 1년 차 직장인, 월급 250만 원 중 적금 100만 원 외 매월 30만 원으로 주식 입문 희망 |
| **투자 성향 & 고민** | "주식 시작해야 돈을 모은다는데, 재무제표는 외계어 같고 차트만 보면 머리가 아파요. 상장폐지만은 절대 당하고 싶지 않아요." |
| **핵심 Pain Points** | 1. **공시 울렁증**: DART 사이트에 들어가면 수십 쪽 분량의 텍스트에 질려 1분 만에 닫음.<br>2. **개념과 현실의 괴리**: '영업이익'과 '당기순이익'의 차이를 교과서로 봐도 실전에서 어떤 의미인지 모름.<br>3. **시간 부족**: 퇴근 후 1~2시간씩 각 잡고 금융 강의를 들을 체력과 여유가 없음. |
| **Easy-DART의 솔루션** | - **출퇴근 3분 마이크로 러닝**: 지하철에서 스마트폰으로 가볍게 즐기는 1분 퀴즈와 3초 스와이프 심사.<br>- **체험 기반 위험 회피**: 게임 속에서 상폐 지뢰를 직접 요격하고 회피해보며 본능적인 위험 감별력 체화.<br>- **소비 메타포 환산**: "올리브영 립스틱 몇 개를 팔아야 이 회사의 영업이익이 될까?" 같은 직관적 비유 해설. |

## 🏢 2. 20대 일상 기업 탐색 & 소비 체감 환산기 (Company List & Metaphor)

20대 사회초년생이 매일 이용하는 일상 소비 브랜드를 통해 DART 전자공시의 문턱을 낮추고, 직관적인 소비 환산 경험을 제공합니다.

### 2.1 4대 일상 소비 카테고리 (20개 기업 라인업)
- 💄 **뷰티 & 패션**: CJ올리브영, 무신사, 아모레퍼시픽, 에이블리, F&F
- 🟢 **IT / 플랫폼 / 콘텐츠**: 네이버, 카카오, 당근, 하이브, 크래프톤
- ☕ **식음료 / 카페 / 배달**: 스타벅스, 배달의민족, CJ제일제당, CU(BGF리테일), 오뚜기
- 🚗 **모빌리티 & 라이프**: 현대자동차, 기아, 아성다이소, CJ CGV, 야놀자

### 2.2 실시간 소비 체감 환산기 (Metaphor Calculator)
- 사용자가 자주 결제하는 브랜드와 금액(예: 올리브영 35,000원)을 입력하면, 실제 DART 정기공시 영업이익률을 바탕으로 **"이 기업이 남긴 순수 이익금"**과 **"대표 상품(독도토너, 아메리카노 등) 몇 개치 순이익인지"**를 실시간으로 환산해 보여줍니다.
- 1만 원, 3만 원, 5만 원, 10만 원 빠른 입력 칩(Preset Chips)과 부드러운 반응형 바운스 인터랙션을 제공합니다.

## 📊 3. 기업 공시 상세 파헤치기 (Company Details & Financials)

난해한 재무제표를 20대 눈높이에 맞춰 직관적인 비주얼 파이프라인과 AI 요약으로 해설합니다.

### 3.1 손익계산서 4대 핵심 지표 시각화
- **매출액(Revenue) ➔ 매출원가/판관비(Cost) ➔ 영업이익(Operating Profit) ➔ 당기순이익(Net Profit)**의 자금 흐름을 단계별 카드와 진행 바로 한눈에 파악할 수 있도록 시각화했습니다.
- "매출 1만 원을 벌면 통장에 진짜 남는 돈은 얼마인가?"를 직관적인 마진율 퍼센티지(%)와 함께 안내합니다.

### 3.2 3개년(2023~2025) 실적 추이 및 YoY 비교
- 연도 탭 버튼 클릭 시 즉시 2023, 2024, 2025년의 공시 지표로 전환되며, 전년 대비 성장률(YoY)을 실시간으로 계산해 표시합니다.

### 3.3 DART 원본 재무제표 표 & Gemini AI 3줄 요약
- **DART 원본 표 모아보기**: 실제 전자공시 감사보고서 원본 서식의 주요 계정과목과 수치를 그대로 제공하여 공시 원문 독해 훈련을 지원합니다.
- **Gemini AI 정밀 요약**: 3줄 핵심 실적 요약, 3대 비즈니스 강점(Good Points), 주요 리스크(Risks)를 일목요연하게 브리핑합니다.
- **기업 맞춤 복습 퀴즈**: 상세 페이지 하단에서 해당 기업의 핵심 재무 지표를 퀴즈로 바로 점검할 수 있습니다.

## 🕹️ 4. 게이미피케이션 & 인게임 AI 시스템 (Game-based Learning & Quiz)

단순한 지식 전달을 넘어, 3대 금융 아케이드 게임과 Gemini LLM 인공지능을 결합하여 실전 공시 감별력을 체득하도록 돕습니다.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    🕹️ Easy-DART 3대 정예 아케이드 라인업                 │
├─────────────────────────┬─────────────────────────┬─────────────────────┤
│ 🧠 Machine 01           │ ⚖️ Machine 02           │ 🏎️ Machine 03       │
│ 주식 & 회계 기초 퀴즈   │ DART 실전 투자 심사관   │ DART 급행 레인 러너 │
│ [ 💡 문해력 배틀 ]      │ [ ⚡ 3초 뇌지컬 ]       │ [ 🕹️ 반사신경 ]     │
│ 62종 대용량 무한 퀴즈   │ 실제 공시 카드 BUY/SELL │ 차선 변경 호재 획득 │
└─────────────────────────┴─────────────────────────┴─────────────────────┘
```

### 4.1 3대 정예 금융 아케이드
1. **🧠 Machine 01: 주식 & 회계 기초 퀴즈 아레나**
   - 손익/재무/감사보고서/CB·증자/배당/실전공시 6대 분야 **62문항 대용량 데이터베이스** 완비.
   - 2-Level 피셔-예이츠 셔플로 순서가 무작위 순환되어 무한 스트리밍 플레이 지원.
2. **⚖️ Machine 02: DART 실전 투자 심사관**
   - 20대 일상 기업의 실제 공시 카드를 읽고 제한시간 내 `◀ (손절/SELL)` vs `▶ (매수/BUY)` 판단. 3초 이내 판단 시 번개 보너스(+100P).
3. **🏎️ Machine 03: DART 급행 레인 러너**
   - 3개 차선으로 질주하며 호재(`영업이익 서프라이즈`)는 획득하고, 악재 지뢰(`완전자본잠식`, `대표 횡령`)는 회피하는 동체시력 훈련.

### 4.2 인게임 AI 시스템 (5대 지능형 코칭)
- **1:1 하브루타 오답 처방전**: 게임 오버 시 틀린 공시(예: CB 발행 매수 오판)를 Gemini AI가 소크라테스식 대화로 코칭.
- **무한 실전 공시 시나리오 생성**: 일상 기업의 가상/실전 공시 딜레마 카드를 AI가 실시간 무한 생성.
- **AI 주린이 투자 성향 진단서**: 플레이 로그(반응속도, 호재 탐욕도, 악재 회피율)를 종합 채점하여 '돌격형 불개미 vs 신중한 헌터' 진단 카드 발급.
- **AI 즉시 심화 질문**: 퀴즈 풀이 중 이해가 안 될 때 20대 알바/소비 비유로 3줄 즉시 해설.

### 4.3 무계정(No-Login) 명예의 전당 & 주린이 4단계 승급제
- `localStorage` 기반 원클릭 닉네임 등록 및 실시간 1~5위 랭킹 전광판 운영.
- 🐣 `새싹 주린이` ➔ 🔍 `노련한 지뢰 감별사` ➔ 🐜🔥 `날렵한 여의도 불개미` ➔ 👑 `스마트 머니 (LV.MAX)` 승급 시스템.

## 📈 5. 실전 모의투자 샌드박스 (Mock Investment Pro)

가상 시드머니 1,000만 원으로 20대 일상 기업 주식을 직접 매매해보며, **"공시를 확인하지 않은 투자가 얼마나 치명적인지"**를 안전한 가상 환경에서 체감하는 시뮬레이터입니다.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    📈 Easy-DART 실전 모의투자 핵심 루프                 │
├─────────────────────────┬─────────────────────────┬─────────────────────┤
│ 💰 가상 시드 1,000만원  │ ⚡ 5대 실전 매매 전략   │ 🛍️ 인생역전 플렉스 샵│
│ 초기 자본금 즉시 지급   │ 무지성 풀매수 vs DART   │ 펜트하우스 구매부터 │
│ No-Login 자동 계좌 생성 │ 정밀분석 3회 분할매수   │ 한강물 수온계까지!  │
└─────────────────────────┴─────────────────────────┴─────────────────────┘
```

### 5.1 5대 실전 매매 전략 & 확률 매커니즘
- 💣 **무지성 풀매수**: 공시 미확인 뇌동매매 시 **90% 확률로 3턴 뒤 -45% 폭락 및 3개월 강제 락업** 발생.
- 🚀 **야수의 풀신용 (2.5X)**: 2.5배 레버리지 빚투로 급등 시 대박, 15% 하락 시 **즉시 반대매매(마진콜) 계좌 강제 청산**.
- 🔍 **DART 정밀분석 분할매수**: 영업이익률 및 부채비율 확인 후 3회 분할매수 시 **75%~88% 고승률 안정 수익**.
- 💧 **물타기 vs 불타기**: 평단가 인하 및 추세 추종 수익 극대화 전략 시뮬레이션.
- 📉 **하락장 공매도 (숏 베팅)**: 분식회계, 감사의견 거절 등 부실 공시를 선제 포착하여 하락 시 수익 실현.

### 5.2 실시간 돌발 공시 이벤트 & 파산 회생 퀴즈
- **돌발 공시 발생**: 턴 진행 시 `[유상증자 500억]`, `[전환사채(CB) 덤핑]`, `[어닝 서프라이즈]` 등 실제 DART 공시가 기습 발생하여 주가 급변.
- **파산 회생 지원금**: 누적 손실 -50% 초과 시 '골판지 박스 거지 핑거'가 등장하며, **유상증자/감사의견 복습 퀴즈**를 통과해야 회생 지원금(500만 원)을 지급받는 교육적 안전장치 탑재.

### 5.3 인생역전 플렉스 상점 (Flex Shop) & 인벤토리
- 모의투자 수익금으로 **'한강물 수온계(1,000원)'**부터 **'여의도 파크원 펜트하우스(150억)'**까지 다양한 유쾌한 아이템을 구매하고 보관할 수 있는 도파민 보상 시스템.

## 🚀 8. 빠른 시작 가이드 (Quick Start)

### 8.1 백엔드 환경변수 설정 (`.env`)
루트 경로의 [`.env`](.env) 파일에 API 키를 입력합니다:
```env
DART_API_KEY=your_dart_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
HOST=0.0.0.0
PORT=8080
```

### 8.2 원클릭 서버 실행 (`run.sh`)
Git Bash 터미널에서 아래 명령어를 실행하면 가상환경 구성, 패키지 설치, 풀스택 서버 구동이 원클릭으로 진행됩니다:
```bash
bash run.sh
```

- 📊 **기업 공시 상세**: `http://localhost:8080/company-details?company=olive`

- 📈 **실전 모의투자**: `http://localhost:8080/mock-invest`
